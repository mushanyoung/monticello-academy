# 架构

单个 Workers 模块提供网页 API 和 email handler；Vite 构建 React 与 Tailwind 静态资源。D1 保存关系和可检索文本，R2 保存 MIME 原件及附件。单体适合三班低流量邮件档案。

生产不导入测试样例。邮件身份、收件关联、索引和安全约定随实现同步补全。

## 邮件身份与原子关联

原始 Message-ID + 发件人产生主身份；缺失时用规范化正文、发件人、标题、发送时间和附件内容 SHA-256 指纹。内容指纹也有唯一约束，可合并不同投递 ID 的相同内容。收件列表不参与指纹。D1 batch 事务写入邮件、附件元数据和多对多班级关联，重复与并发投递只扩充关联。不同日期的相同通知不会误合并。

To/Cc/Bcc、List-ID、List-Post、投递头及普通转发的收件人行识别三个精确列表地址。一个或多个 message/rfc822 附件逐封展开，最多三层、每批最多 20 封归档记录；保留每封原件的 MIME 字节、日期、Message-ID 和附件。班级按每封原件自己的邮件头识别，不继承批量转发外层的收件列表；管理接口显式传入的班级可应用于整批。只含原件的转发包装不单独展示；外层带有其他附件时也保存外层，避免丢失附加文件。普通转发丢失 Message-ID 时不能保证跨转发形式去重，优先使用原始 .eml。没有识别到班级的邮件仍保存在 All classrooms，不能猜测班级。

整批先解析和校验，任一原件格式错误或超过批次/嵌套上限都在写入前拒绝。通过校验后逐封执行现有 R2 写入和 D1 事务；存储故障可能已保存前面的原件，重投整批会幂等补齐。20 封上限使当前每封两次 D1 调用不超过免费计划每次 Worker 调用 50 次查询的限制；参见 [D1 limits](https://developers.cloudflare.com/d1/platform/limits/)。

R2 使用内容寻址 key，在 D1 事务前完成写入。失败会抛出以便平台重试；失败批次可能留下无引用对象，暂不自动清理以免误删并发写入。原始 MIME 始终保留。每封最多 20 MiB、40 个附件；正文索引前 100k 字符、头部前 20k、组合搜索前 200k，避免超出 D1 行大小。文本附件索引前 100k 字节；二进制附件当前可按文件名查找，PDF/OCR/Office 文本提取待实际课程样本确定。

## 查询与公开访问

用户明确选择公开访问。GET API、正文与附件公开；写入只能通过允许的发件人 email handler 或带 IMPORT_TOKEN 的管理接口。令牌用固定长度哈希的 timing-safe 比较；生产没有测试令牌。MAIL_CONFIG Secret 配置的学校域名与转发人允许入站，其他信封发件人拒绝。邮件默认在隔离 iframe 中显示净化后的原始 HTML，保留颜色、字体、列表和表格，可切换纯文本。GET `/api/mail/:id/content` 从已有 R2 原件按需解析，不需要迁移或重新导入历史邮件；CID 图片通过内容哈希关联已入库附件。附件默认强制下载；仅 PDF、常见栅格图和纯文本允许隔离预览。禁止缓存 API，响应设置 nosniff。

搜索对组合索引做 Unicode 小写后的字面子串匹配，支持中文和标点，无 SQL/FTS 查询语法注入。小规模校园档案优先可预测语义；参数绑定，结果每页 30 条，日期和 ID 稳定排序。

邮件地址与允许发件人从 MAIL_CONFIG Secret 解析并验证，前端仅接收公开收件地址。D1/R2 绑定与路由由 cf CLI 从 Cloudflare 拉取到忽略文件；公开源码无真实部署参数。

## 原始邮件显示边界

`sanitize-html` 只允许排版标签和明确属性，去除脚本、事件、表单、iframe、SVG、导航 meta/base；链接固定新窗口并设置 noopener/noreferrer。为保留学校邮件样式，明确允许 `<style>`（`allowVulnerableTags` 的限定例外）：HTML 只由专用端点输出，绝不插入应用 DOM；端点 CSP 和 iframe sandbox 均禁止脚本、表单及顶层导航，CSP 在单独打开端点时同样生效。allow-same-origin 只供父页面测量内容高度，禁止同时添加 allow-scripts。

外部图片默认从 img 属性中移除，srcset 不保留；CSS 网络请求同时由 CSP 拦截。用户点击 Load external images 后仅开放图片 http(s) 来源，外部样式表、字体、脚本和连接仍禁止。CID 仅映射同封邮件已归档的 PNG/JPEG/GIF/WebP，data 图片也仅允许这些类型。图片和表格宽度适配容器；超长邮件高度封顶后在框内滚动。格式加载失败回退纯文本并允许重试。真实邮件和截图只可保存在忽略的本地目录。
