# 中英文约定

网站支持 zh（简体中文）和 en（英文）。先使用 localStorage 中的有效手动选择，再按 navigator.languages 的顺序匹配中文或英文；没有可用偏好时选中文。右上角随时切换，同一客户端刷新或导航后保留，不影响其他客户端。存储受限时仍允许当前标签页切换。html lang、日期格式、可访问标签和空态一起更新。

UI 文本必须同时维护中文、英文。真实邮件与课程内容使用 Terra 翻译，分别持久化两种语言；动态翻译不能混入公开源码或测试数据。原文差异在两种语言中都保留，没有人工确认或批准步骤。后续任务修改任何展示或入库路径时，必须验证两种语言。

`src/web/messages.ts` 以英文原文作为类型化 key，并为每个 key 提供中文；使用 useI18n().t，插值占位符在两种语言中必须一致。日期使用同一 hook 的 displayDate。测试解析 JSX，防止正文、可访问标签与 placeholder 绕过本地化；语言按钮和纯装饰 SVG 单独处理。新增组件必须遵守这套约定。

按用户选择，保留原始 PDF，不生成中文 PDF 文件；网站中的邮件、结构化课程和每日提醒保存并展示完整中英文版本。

## 内容翻译协议

translationTemplate 只提取用户可见文字、图片 alt/title、邮件标题与附件展示名，以及课程中的描述字段。日期、ID、语言无关的状态与来源关系不交给模型修改。HTML 保留原始字符范围，翻译后只替换文字并转义；CSS、链接目标、CID 图片、表格和标签结构保持不变。英文文字未变化时直接保留原始 HTML 字节，包括实体和空格。

每批最多 150 个片段、24k 字符，单片段最多 16k 字符。模型必须按 ID 完整返回 en/zh；缺片段、重复 ID 或修改原文数字、地址和链接时拒绝整批。语言版本不允许借翻译注入 HTML。相同文字复用片段，长纯文本分块且保留空白。

translation_jobs 按实体、来源内容和翻译器版本去重；translation_parts 保存已完成分块与响应 ID。mail_localizations 与 plan_localizations 分别存两种语言，记录来源快照；后续发布必须验证来源仍是当前版本，防止旧翻译覆盖新课程。没有人工审批状态。

数字、日期、时间、URL 和邮箱先替换成不可改写的占位符；模型必须原样返回，服务端恢复原始值后再次检查。模型不能修改课程日期、来源页码和附件关联。邮件 HTML 存在 R2，正文、标题、附件展示名和搜索索引存在 D1；原始 MIME、PDF 和其他附件保持原件，下载使用原文件名。搜索同时覆盖两种语言的正文、HTML 可见文字、附件展示名与来源课程内容。每日提醒直接取对应语言的持久化课程，避免再次生成时遗漏原文差异。

TranslationWorkflow 使用已有 OPENAI_API_KEY 和 gpt-6.1-terra（low reasoning），通过 Responses background 请求处理有界分块。单个 HTTP/持久化步骤失败最多自动重试三次，已完成分块复用；仍失败则记录安全错误并用已有通知 outbox 发邮件。通知失败继续定时重试。任务超时自动终止并通知。发布 en/zh 使用同一个 D1 batch，来源变化时旧任务标为 superseded，不覆盖新数据。缺少目标语言时显示原文并明确说明翻译正在生成或暂不可用。

LESSON_CONFIG.enabled 同时控制自动课程解析和翻译；新邮件、管理导入、自动课程提取和管理课程写入都触发翻译。15 分钟补偿扫描补齐漏掉的入队和既存内容，翻译补扫不限邮件日期。开发环境关闭真实翻译；CI 仅替换 OpenAI HTTP 边界，D1、R2、Workflows 和通知绑定均使用真实本地运行时。

GET 邮件、HTML、课程与提醒 API 接受 `lang=zh|en`；未指定时按 Accept-Language 权重匹配，无匹配则中文。客户端请求始终携带当前选择的 lang。管理翻译端点与历史回填操作见 docs/operations.md。实际邮件与译文、截图只能保存在 Git 忽略的私有目录。

翻译指令变更递增 TRANSLATION_VERSION。版本 2 明确区分数字原值与月份／星期名称：数字保持，名称译成中文；班名与 UI 一致，英语教学目标保留原始字母、词汇和拼读形式。发布还要求同一来源不存在更新任务，防止旧翻译器覆盖新版本；入队新版本时停止该实体仍运行的旧版任务并标为 superseded。历史语言版本在更新完成前仍可查看。

邮件 iframe 按目标语言设置 html lang 和标题，净化时去掉原始内部元素的 lang 属性，避免 Word 等邮件中的 en-US 覆盖中文文档的朗读语言。文字翻译可以把连接词转换为标点；验收样式应比较标签、CSS、布局属性、链接和图片地址，不能以译文是否仍包含字母来推断结构变化。

课程年月选择使用已入库月份的下拉列表，由 Intl 按站内语言生成完整年月标签（例如 2040年9月／September 2040）。不使用年份数字框或原生 input[type=month]。选择即切换，不设提交按钮；值仍是标准 YYYY-MM，并保留班级筛选。测试须验证两种语言的选项、空档案提示及即时导航结果。
