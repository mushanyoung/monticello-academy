# 验证策略

Unit tests 验证班级识别、跨列表去重、日期与课程等业务边界。存储/API 测试使用真实本地 Workers 的 D1 / R2，不以 mock 返回值代替入库结果。

Playwright 在桌面和手机尺寸验证实际用户流程；测试邮件仅为构造数据，不能写入生产。日期固定或由校园时区计算。

统一命令 `pnpm check`。失败诊断见 `test-results/` 与 `playwright-report/`，CI 上传保留 14 天。分别说明本地与远端 Actions 结果。

已覆盖原始 ID 与无 ID 去重、嵌套 .eml、精确列表识别、HTML 转文本、输入上限、并发三班投递、实际附件下载、文本附件搜索、字面百分号查询、排序、无效筛选与导入鉴权。API 测试通过 cf dev 运行，使用生产相同的 D1 SQL 和 R2 binding。

当前包含 53 个 unit cases 和桌面／手机各 24 个 e2e cases：今天／明天提醒、月计划与原始邮件跳转、实际下载、筛选搜索、空结果、加载失败重试、无横向溢出；以及通过 `/cdn-cgi/local/email` 调用真实 email handler 的接收／拒收路径。批量转发覆盖原始 MIME 字节和日期保留、base64 与 7bit、独立班级识别、重复投递去重、嵌套/数量边界、额外附件保留、无效批次不发生部分写入。e2e 开始仅清理 `.cloudflare/test-state`，不会清理开发或远端数据库。转发模拟的 To 与信封地址不同为正常现象，拒收用例的运行时日志为预期诊断。

配置测试验证 test/development 不读取生产缓存、不完整邮件映射被拒绝；公共配置 API 只暴露收件入口，不返回允许转发人和班级邮箱。

Unit XML 保存在 `test-results/unit.xml`，Playwright 产物在 `test-results/e2e/`，避免浏览器测试清理输出时覆盖 unit 报告。

公开源码检查测试覆盖 Git 身份邮箱的限定例外：同一邮箱出现在文件、提交说明、伪造头部时仍拒绝；凭据和部署参数在作者字段内也不会绕过检查。

邮件显示测试覆盖字体、颜色和表格保留、CID 图片实际加载、危险 HTML 清理、CSP/sandbox、外图默认不发请求及按需加载、纯文本切换和格式失败重试；长发件人地址不得撑宽页面，浏览器不得出现脚本异常。

附件显示验证：已显示图片不重复列出，纯图片邮件不留空附件区；普通图片、PDF、无正文引用或被 CSS 隐藏的 inline 文件保留，图片请求失败可独立下载，切换纯文本恢复全部文件，重试成功后再次过滤。测试通过实际归档、预览及下载请求检查文件未被删除。

模型就绪检查覆盖鉴权、缺失密钥、不可用模型与异常提供商响应，错误正文不泄漏到客户端；测试不访问真实 OpenAI 服务。

课程结构测试覆盖班级／年月识别、跨月拆分、专属月与相邻月日期优先级、无效／重复日期、来源页码、停课与活动矛盾、周区间异常，以及非课程附件识别。

课程没有审批步骤：测试验证 draft 被拒绝、已有内容保留，以及跨月重叠条目全部保留。

课程 Workflow e2e 使用实际本地 D1、R2、Workflows 与 sendEmail binding；只有 OpenAI HTTP 边界由独立本地服务提供合成 PDF 响应，不访问真实模型。验证自动入队、跨月发布、来源差异同时展示、补齐班级、重复投递去重、瞬时错误重试、持续错误通知、原有计划保留、重试操作和管理结果鉴权。

PDF 搜索用例查询仅存在于模型结果、未出现在邮件正文或文件名中的每周学习目标；同时验证手机每日卡片可展开每周目标。

课程接收还通过真实 email handler 验证；夹带的无关 PDF 自动 ignored，定时补偿不产生错误通知。

双语 UI 验证客户端语言顺序、中文默认回退、手动选择跨导航与刷新保留、不同客户端相互独立，以及两种语言的手机／桌面布局。类型约束和 JSX 静态测试防止遗漏翻译，插值参数须保持一致。

内容翻译测试通过实际 D1、R2 和 Workflow 持久化两个语言版本，验证 HTML 样式与 CID 图片、原件字节、中文 HTML/课程搜索、数字与来源 ID、原文差异、每日与每周信息；同时覆盖旧任务不能覆盖新课程、输入鉴权、翻译失败通知和成功重试。模型仅在 HTTP 边界使用合成双语文本，生产回填必须另行验证真实模型结果和两种语言的实际页面。

翻译器版本更新的并发发布用实际迁移和 SQLite 执行生产 D1 SQL，验证旧任务不能覆盖新版本的任一语言；浏览器用例继续覆盖真实 D1 的来源更新竞争。
