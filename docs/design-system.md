# Family notebook 设计系统

参考 MotherDuck 的轻松线描、纸面质感与清晰排版；采用原创校园手帐语言，不复制标志和插画。

纸张 `#fcf8f0`，墨紫 `#30233e`，主紫 `#7050a0`，橙 `#ef9258`，淡紫 `#eee7f5`，浅杏 `#fce8d8`，辅助绿 `#e7eee3`。深色正文在浅底上；橙用于装饰，状态同时用文字。

标题 Fraunces，正文 DM Sans，小注释 Caveat。字体本地打包。原创 SVG 太阳、小鱼与积木作为班级符号，细墨线、不规则圆角和小幅旋转。正文保持端正，避免装饰影响阅读。

站点文字使用 rem 字级，跟随浏览器默认字号：正文、表单输入和主要按钮 16px（1rem），次级信息 14px，最小标签 12px，邮件列表标题 18px。手机与桌面使用同一阅读基准，不在窄屏缩小正文；标题与分段控件可换行，保留点击空间。邮件原文在独立文档中保留发件人的字号，不受站点字级覆盖。

手机优先：首屏今天/明天与三班重点，底部导航，触控目标至少 44px，不依赖 hover。桌面侧栏与宽阅读区。长文本自动换行。

表单有标签、焦点清晰、尊重 reduced-motion；加载、空白、失败均有具体提示。无课程数据写“尚未整理”，不能表达为“没有注意事项”。邮件与课程来源互相链接。

## 已实现的界面

桌面固定侧栏、手机底部导航；今天／明天与班级筛选直接进入每日卡片。月份页面使用原生 month input 和可展开日程，来源邮件直达。Mailbox 支持原生 GET 搜索表单（查询 URL 可分享、刷新和后退）、稳定分页、双栏邮件详情，手机单栏阅读；附件下载与受限类型预览。

原创太阳、小鱼、积木与小花园均为 SVG，静态图形无需生成图片依赖。所有字体随包提供，无第三方字体请求。移动首屏缩短装饰区，优先给日程留空间。CSS 使用低特异性的 :where 限定祖先，保留 recommended 规则，不禁用 specificity 检查。

手机打开邮件详情时收起顶部装饰、筛选与搜索区，让正文更早进入视野；返回链接恢复邮箱列表。Skip to content 仅键盘 focus-visible 时显示。

邮件原始排版使用独立白色阅读画布，保留邮件自身字体、颜色、表格和内嵌图片，不套用站点装饰字体。Original formatting / Plain text 切换保持原文可读；外部图片有明确加载按钮，格式失败显示文本并可重试。手机图片适应画布宽度，内容高度随排版变化调整。

附件区仅列出当前正文没有显示的文件，数量与列表一致。确认原始视图中的内嵌图片加载成功且有可见布局后，才移除重复条目；未引用、隐藏、加载失败的图片和普通文件保留。纯文本或格式失败时展示全部文件，全部图片已在正文显示时不留空附件区。邮箱列表的数字表示归档文件总数（含内嵌图片），通过提示与辅助文本说明。

每日卡片优先显示当日主题和携带／穿戴要求，前三项活动直接展示，其余活动、每周目标和整月提醒使用原生 details 在手机上展开。月计划显示每周重点和来源 PDF 页码；原文有差异时直接展示各方说法，不出现人工确认状态。长 PDF 文件名允许折行。
